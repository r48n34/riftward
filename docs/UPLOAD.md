# Publishing RIFTWARD

Everything needed for a public release is generated by:

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_export.ps1 -Zip
```

which writes:

| Path | What it is |
|---|---|
| `release/windows/` | `RIFTWARD.exe` + `RIFTWARD.pck` + `README.txt` — the exact folder to upload |
| `release/RIFTWARD-win64.zip` | the same three files zipped (~40 MB) — what you give people |
| `release/SHA256SUMS.txt` | checksums so downloads can be verified |
| `release/store/cover_630x500.png` | itch.io cover art |
| `release/store/banner_1200x630.png` | wider card for blogs / social |
| `release/promo/` | advert set: hero, vista, square, vertical, feature grid + clean captures — see [release/promo/README.md](../release/promo/README.md) |

Page copy is ready to paste in [STORE_PAGE.md](STORE_PAGE.md).
"Play in the browser" is **not** available today — read [WEB_PORT.md](WEB_PORT.md) before promising it to anyone.

## Option A — itch.io (recommended, ~15 minutes)

itch.io is the default home for indie and Godot games: free, no review queue, unlimited downloads, built-in devlog and analytics.

### 1. One-time setup

1. Create an account at <https://itch.io>, verify the email.
2. Optional but worth it — install **butler** (itch.io's upload CLI) from <https://itch.io/docs/butler/>. It makes updates one command instead of a browser upload.

### 2. Create the project page

Dashboard → **Create new project**, then:

| Field | Value |
|---|---|
| Title | `RIFTWARD` |
| Project URL | `riftward` (the page becomes `<yourname>.itch.io/riftward`) |
| Short description | `Drop into the Reach. Build what survives.` |
| Classification | **Game** |
| Kind of project | **Downloadable** — do *not* choose HTML. This is a Windows desktop build. |
| Pricing | `No payment` (or `$0 or donate`) |
| Uploads | upload `release/RIFTWARD-win64.zip`, then tick **Windows**. Leave *"This file will be played in the browser"* unchecked. |
| Cover image | `release/store/cover_630x500.png` |
| Screenshots | 5–8 from `ui/_screenshots/` plus `captures/qa_exfil_ship.png` and `tests/artifacts/deployment.png` |
| Genre / tags | Shooter · `first-person` `sci-fi` `extraction` `singleplayer` `godot` `fps` |
| Visibility | **Draft** first — preview with *View page*, then switch to **Public** |

Everything in the long-description box can be pasted straight from [STORE_PAGE.md](STORE_PAGE.md).

### 3. Uploading with butler (updates)

```powershell
butler login
butler push release/windows <your-itch-name>/riftward:windows
butler status <your-itch-name>/riftward
```

After that, every rebuild is one command: `tools/build_export.ps1 -Zip` then `butler push …`.

### 4. After publishing

- Download your own build once from a different browser to confirm the zip is intact.
- Keep a version string on the upload (`0.1.0`) so players can tell builds apart.
- Decide whether the page is free forever or has a minimum price; you can change it at any time.

## Option B — GitHub Releases (free, no store page needed)

Good for a private link, testers, or an open-source release.

```powershell
git init
git add .
git commit -m "RIFTWARD 0.1.0"

# create an empty repo on GitHub first, then:
git remote add origin https://github.com/<you>/riftward.git
git push -u origin main

gh release create v0.1.0 release/RIFTWARD-win64.zip `
  --title "RIFTWARD 0.1.0 - Windows" `
  --notes-file docs/PLAYER_README.txt
```

`.gitignore` already excludes `build/`, `release/` and `.godot/`, so the 104 MB executable never enters git history — only the Release asset does.

GitHub's hard limit is 2 GB per release asset, 100 MB per file inside git; the zip is 40 MB, so this is comfortable.

## Option C — Steam (only once you want money or audience)

- **$100 USD Steam Direct fee per app**, non-refundable, plus a Steamworks partner account.
- You upload depots (content folders), not a zip; expect a ~2–5 day store review and a 2-week minimum "coming soon" window by default.
- Godot needs no extra SDK for a basic build; Steam achievements/cloud are opt-in via GodotSteam and are a separate integration.
- Worth doing only after itch.io proves people actually play it.

## Before you publish — honest checklist

- [ ] Build is current: `tools/build_export.ps1 -Zip` ran without errors.
- [ ] `release/windows/RIFTWARD.exe` launches and the smoke checks pass (`--shoot-smoke`, `--inventory-smoke`).
- [ ] Page does **not** promise multiplayer, co-op, or browser play — none of those exist in this build.
- [ ] You warn about the **SmartScreen** prompt: the build is unsigned, so Windows shows "Windows protected your PC" on first launch → *More info* → *Run anyway*.
- [ ] Minimum specs on the page match [PLAYER_README.txt](PLAYER_README.txt).
- [ ] Someone else downloaded and ran it on a clean machine.
- [ ] You are allowed to publish every asset — this project uses only procedurally generated content plus OFL fonts, so it is clean.

### Things that will bite you later

- **No auto-updater.** Players must re-download to update. If that matters, add a version check against your page and tell them.
- **Saves live in `%APPDATA%\Godot\app_userdata\RIFTWARD`.** Reinstalling elsewhere does not move them; a player who "uninstalls" by deleting the folder keeps their profile.
- **Unsigned binaries** get quarantined by some corporate antivirus. A code-signing certificate (~$200–400/year) is the real fix, and only worth it once downloads matter.
- **Analytics are limited** on itch.io downloads. If you want numbers, add a devlog post and watch page views, or host a minimal landing page with a click counter.
