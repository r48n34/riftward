RIFTWARD
Drop into the Reach. Build what survives.

A single-player, first-person extraction shooter.
Version 0.2.0  -  built with Godot 4.7.2

------------------------------------------------------------
FIRST DROP
------------------------------------------------------------
New profiles should start with FIELD TRAINING on the main menu.
It teaches movement, shooting, abilities, looting and extraction in
five short stages. You can skip it from the pause menu and replay it
from the main menu at any time.

Five planets, twelve maps, eighteen weather states and a day/night cycle
are available from Quick Deploy and the Hub. Pick a mode to change the
drop: NORMAL, QUICK (2x clock), BLACKOUT (night insertion), GAUNTLET
(early Collapse) or ONSLAUGHT (elite surge). Water can be swum; lava burns.
Look for under-reach hatches at vaults, stockades, Choir posts, colony
ruins and the derelict freighter: descend, break the guardian, return.
Twenty world events can fire in a run; watch the Reach Event banner for
weather, convoys, bounty brokers and storm shifts.

The armory, locker, skills, squad and outpost screens are image-first:
weapons and gear show their silhouettes, Wardens and Driftlings show
portraits, and the outpost is a clickable 8x8 diorama. Display settings
(window mode, resolution, render scale, anti-aliasing, frame cap and quality)
are in Settings -> Display.

------------------------------------------------------------
HOW TO PLAY
------------------------------------------------------------
1. Keep RIFTWARD.exe and RIFTWARD.pck together in this folder.
   The game will not start if the .pck is missing or moved.
2. Double-click RIFTWARD.exe.
3. The first launch can take a few seconds while shaders compile.

------------------------------------------------------------
REQUIREMENTS
------------------------------------------------------------
- Windows 10 or 11, 64-bit
- DirectX 12 capable GPU (Forward+ renderer)
- 4 GB RAM minimum, 8 GB recommended
- About 150 MB free disk space
- Keyboard and mouse (gamepad supported)

------------------------------------------------------------
CONTROLS (keyboard / mouse)
------------------------------------------------------------
Move .................. WASD          Fire ................ Left mouse
Look .................. Mouse         Aim down sights ..... Right mouse
Sprint ................ Shift         Reload .............. R
Crouch / slide ........ Ctrl or C     Interact / revive ... E
Jump .................. Space         Ability 1 / 2 ....... Q / F
Ultimate .............. X             Melee / quick knife . V
Frag grenade .......... G             Weapon slots ........ 1 / 2 / 3 / 4
Inventory and satchel . I             Call extraction ..... E or H
Squad command ......... Z             Pet command ......... B
Map overlay ........... M             Pause ............... Esc

Every action can be rebound in Settings -> Controls. Gamepad is supported
throughout, including menu navigation.

------------------------------------------------------------
WHERE YOUR PROGRESS IS SAVED
------------------------------------------------------------
%APPDATA%\Godot\app_userdata\RIFTWARD

Delete that folder to reset progress and settings.

------------------------------------------------------------
UNINSTALL
------------------------------------------------------------
Delete this folder, then delete the save folder above if you also
want to remove your profile.

------------------------------------------------------------
KNOWN LIMITS
------------------------------------------------------------
- Single-player and offline only. There is no co-op, PvP or online play.
- This build is unsigned, so Windows SmartScreen may warn on first launch:
  choose "More info" then "Run anyway".
- No mid-run save. Quitting during a deployment abandons that run;
  meta progress is saved when you return to the hub or finish a run.
- No installer and no auto-updater. To update, replace this folder with
  the newer download (your save folder is untouched).
