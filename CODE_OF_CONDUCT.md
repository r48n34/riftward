# Code of conduct

## The short version

Be decent. Assume good intent, criticise the work rather than the person, and remember that this is a
hobby-scale project maintained by volunteers who owe you nothing and are not on call.

## Expected behaviour

- Give technical criticism that is specific and actionable.
- Accept that maintainers may decline a change that does not fit the project's direction, even if it is
  technically correct.
- Respect that the game's design decisions (single-player only, no co-op, no monetisation) are
  deliberate, not oversights to be argued around in every issue.

## Unacceptable behaviour

- Harassment, personal attacks, or discriminatory language of any kind.
- Publishing someone's private information.
- Spam, repeated off-topic posting, or reopening the same declined request.
- Shipping other people's assets or code without attribution or a compatible license.

## Scope

This applies to issues, pull requests, commit messages, discussions and any project space.

## Enforcement

Maintainers may edit or delete comments, close threads, and block accounts that break these rules.
There is no formal committee; enforcement is at the maintainer's discretion.

To report a conduct problem, contact the repository owner privately rather than opening a public issue.
For security problems, use [SECURITY.md](SECURITY.md) instead.
